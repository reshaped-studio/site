# ReShaped

<!-- many-hats -->

This project uses two shared systems.

**Team.** Read `many-hats/AGENTS.md` before selecting or acting as a team member. Role definitions live in `many-hats/agents/`.

**Workflow.** Design Dash is the primary workflow. Read `design-dash/AGENTS.md` and `design-dash/method/method.yaml`. A dash runs phases P0 through P8 and ends in a Design Plan. Write dash artifacts at this project's `dashes/<slug>/`. Do not write them inside the `design-dash/` submodule.

The human owns goals, consequential tradeoffs, approvals, and external actions.

Cursor discovers skills from `.agents/skills/` and specialists from `.cursor/agents/`.
